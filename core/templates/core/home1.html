What is ForgotYourEmail?

ForgotYourEmail is an Android app designed to help users reconnect with Gmail accounts, organize their inbox, and stay productive. It’s built using Kotlin for Android and a robust Django REST API backend for secure data handling.

Key Features

  • 📩 Automatically read and classify emails
  • 📬 Highlight unread and important messages
  • 📆 Create tasks and calendar events from emails
  • ✉️ Smart auto-reply to messages (with consent)
  • 🔒 Full control – data is only accessed with user permission

Privacy and Data Usage

We prioritize your privacy. Gmail data is only accessed after your consent via Google OAuth and used only for approved features. You may revoke access anytime through your Google Account settings.

Data is never shared with third parties or used for advertising. This app is independently developed and is not affiliated with Google.
